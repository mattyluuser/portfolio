ai-01.png and ai-02.png are live on the site — thumbnails for "Barry's
Veggie Dash" and "Elaine's Bothersome Tracker". Drop a replacement in
with the same filename any time to swap an image.

To add another project, copy an <li class="project"> block in the AI
Projects section of index.html, then edit:
  - the .photo thumbnail's data-src → a new file here (ai-03.png, etc.)
  - .project__title  → the project's name
  - .project__desc   → a one-line description
  - the "View →" link's href → the project's real URL

Square, ~1:1 images work best (these render small, 88px wide).
